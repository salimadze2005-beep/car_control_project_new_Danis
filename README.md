# Зрение и управление мобильной платформой

Прототип автономной мобильной платформы на NVIDIA Jetson Xavier. Камера ZED даёт изображение и глубину, TensorRT модель находит конусы трассы, а программа строит целевую точку и рассчитывает команды движения. Управление передаётся на Arduino. С отдельного компьютера можно переключать ручной и автоматический режимы, менять скорость и включать запись.

Репозиторий содержит исходный код системы и примеры экспериментов. Для запуска полного контура нужны сама платформа, камера ZED, Arduino и совместимый TensorRT engine детектора конусов.

## Как устроен проект

- `Jetson Xavier/server.py` — основной цикл, приём UDP-команд, обработка кадров, построение траектории и запись видео.
- `Jetson Xavier/Code/Cone_detector.py` — загрузка TensorRT engine и обработка результатов детекции.
- `Jetson Xavier/Code/Car_control.py` — команды для Arduino и остановка при отсутствии новых команд.
- `Jetson Xavier/Code/Config_load.py` и `Jetson Xavier/config.jsonc` — загрузка и проверка настроек.
- `Jetson Xavier/Code/Web.py` — просмотр текущего видеопотока через браузер.
- `PC/server_send.py` — пульт управления и приём телеметрии.
- `Yolo/` — отдельные скрипты и файлы для проверки детекции.

Захват кадров, детекция и запись разнесены по потокам. Очереди для детекции и результата имеют ограниченный размер, чтобы накопление старых кадров не задерживало управление. Для TensorRT используется отдельный контекст CUDA.

## Подготовка к запуску

На Jetson нужны ZED SDK с модулем `pyzed`, TensorRT, PyCUDA, OpenCV, NumPy, Flask и `pyserial`. На компьютере с пультом нужен `pygame`. Версии зависят от установленного JetPack и ZED SDK; общего файла установки для всех платформ в репозитории нет.

1. Подготовьте TensorRT engine для детекции конусов и укажите его путь в `Jetson Xavier/config.jsonc`, поле `vision.yolo_model_path`. Путь в текущем файле относится к рабочей машине автора.
2. Проверьте классы детектора, частоту кадров, размеры кадра и параметры управления в том же файле.
3. Подключите ZED и Arduino к Jetson. Первый запуск управления проводите при неподвижной платформе.
4. На компьютере с пультом задайте адрес Jetson в `PC/server_send.py`, переменная `JETSON_IP`. Убедитесь, что указан тот же UDP-порт, что и в `network.udp_port` конфигурации.

Запуск сервера из каталога Jetson:

```bash
cd "Jetson Xavier"
python3 server.py
```

Запуск пульта из корня проекта на отдельном компьютере:

```bash
python PC/server_send.py
```

По умолчанию сервер принимает UDP-команды на порту 5005. Веб-поток открывается на порту 5000 компьютера Jetson. Пульт отправляет команды движения и получает ответ с режимом, состоянием камеры и записью.

## Управление с ПК

В окне пульта стрелки отвечают за движение и поворот. Клавиша `A` включает автоматический режим, `S` возвращает ручное управление. `R` начинает запись, `C` останавливает её, `Q` завершает работу пульта. Скорость меняется клавишами `1` и `2`.

## Проверка отдельных частей

Скрипты в `Jetson Xavier/examples/` предназначены для проверки камеры и детектора по отдельности. Код в `Yolo/` относится к экспериментам с моделью и видео. Эти примеры не заменяют проверку собранной платформы: точность детекции, задержка и частота кадров зависят от оборудования, модели и настроек.

В репозитории есть демонстрационные видео и файл стандартных весов YOLO. Для полного контура управления требуется отдельный TensorRT engine детектора конусов; локальный путь к нему указан в конфигурации.
